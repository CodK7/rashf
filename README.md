# رشف · RASHF

منيو مشروبات رشف: موقع ثابت (HTML وCSS وJavaScript) يقرا المنتجات من Supabase.

- `index.html`: الصفحة الرئيسية
- `assets/`: التنسيق والسكربتات والخطوط والصور
- `i18n/`: النصوص بالعربي والإنجليزي
- `assets/js/config.js`: رابط Supabase والمفتاح العام (publishable). هذا المفتاح آمن بالمتصفح لأن قاعدة البيانات محمية بسياسات RLS.
